# 🕵️ El Impostor

Juego de fiesta para jugar con **un solo móvil**, pasándolo de mano en mano.

## Cómo se juega
1. Añade los jugadores (mínimo 3), elige cuántos impostores habrá y las categorías.
2. Pasad el móvil: cada jugador toca la carta para ver su rol en secreto.
   - Los civiles ven la **palabra secreta**.
   - El impostor solo sabe que es el impostor (y, si lo activas, la categoría).
3. Por turnos, cada uno dice una palabra relacionada con la secreta.
4. Votad a quién expulsar. Si pilláis al impostor, aún puede ganar si adivina la palabra.

## Publicarlo en GitHub Pages
Es una web estática (HTML/CSS/JS), sin dependencias ni compilación.
En el repo: **Settings → Pages → Build and deployment → Deploy from a branch**,
elige la rama y la carpeta `/ (root)`.

## Personalizar
Las palabras están en `words.js` (33 categorías, más de 800 palabras). Puedes añadir categorías o palabras nuevas.
